分類題庫：依 Number 順序學習

本版共 200 張卡片，全部設為 New Cards，已清除附件中的舊學習進度與作答紀錄。每張卡片的新卡位置等於排序欄位 Number 的編號（001～200）。答案、圖片、補充內容、模板及局部區域排序保留。

分類名稱

1. 背部：Number 001～014。

2. 上肢：Number 015～102。

3. 胸部：Number 103～142。

4. 腹部：Number 143～200。

主套牌名稱維持「第一次線跑_分類題庫」。分類名稱保留原樣；新卡順序由 Number 的新卡位置決定，不依分類名稱的字母順序。

第一次匯入或匯入到新的 Anki 個人資料

匯入新版 第一次線跑_分類題庫.apkg，允許匯入套牌預設設定。新卡收集順序為「位置遞增／Ascending position」，新卡排序為「依收集順序／Order gathered」，因此新卡會依 Number 出現。每日新卡數上限維持原值；不同日繼續順序，而非一次強制顯示全部 200 題。

目前 Anki 已有同一份題庫時

重新匯入不一定會重設已存在卡片的本機進度。如果希望本機也從 001 開始，請在匯入後操作：

1. 開啟「瀏覽」，切到卡片模式，搜尋 deck:"第一次線跑_分類題庫"，全選這份題庫。

2. 使用「卡片 → 忘記／Forget」將這批卡片設為新卡，並重設複習次數。此步會清除選定卡片的學習狀態。

3. 將「排序欄位／Sort Field」按升冪排列，確認 Number 為 001～200。不要用建立時間排序。

4. 全選，再選「卡片 → 重新定位／Reposition」；起始位置 1、間距 1，取消隨機排序與移動其他卡片位置。

5. 確認主套牌與子套牌的新卡收集順序為「位置遞增」，新卡排序為「依收集順序」。分類名稱不需要修改。

本次只修改附件套牌，沒有直接操作正在使用的 Anki 個人資料庫。

驗證

獨立測試資料庫匯入後，200 張卡片全部為新卡，位置逐張等於 Number；實際排程器的新卡佇列為 001～200。200 張卡片的正反面與圖片均核對通過。
